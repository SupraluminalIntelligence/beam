# Beam 0.1.8

- PR controls above the composer show the PR number, branch, change size, and live CI status. Inspect failed checks, open their logs, or ask the agent to fix them. Create a PR directly from a pushed branch.
- Claude Code and Codex usage limits show plan-window usage and reset times. The account menu provides machine readiness, usage, and quick links to Settings.
- Settings is grouped into You, Workspaces, and Beam, with folder sharing under Machines, a shortcuts reference, and an in-app What's new page.
- Pause desktop notifications for an hour or until tomorrow while the inbox continues collecting messages.
- Invalid or inaccessible repo names no longer lock a thread while attaching a repo.
- Retains the updater, machine-name, scrolling, runner-recovery, and People-menu fixes from 0.1.7.

Signed and notarized Mac installers are available for Apple Silicon and Intel. Existing installations can update through Beam's updater.

**Updating from 0.1.0–0.1.5:** if Restart to update stalls, fully quit Beam after the download finishes, then reopen it. If necessary, quit Beam and replace it using the installer below.

Built from main commit `280cfe6`, including the merged PR status, account/settings, and repo-attachment changes.
