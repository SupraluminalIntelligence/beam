# Beam 0.1.7

- Redesigned Settings with separate workspace, machine, agent-default, and notification pages; clearer account and machine controls.
- Updated composer with consistent controls, an agent/account menu, and Study selection in the chat header.
- Added Opus 5.5 to Claude Code model choices.
- Improved runner recovery and status reporting, run completion after harness failures, and Git landing when a thread's branch moves.
- Fixed the People menu: long machine names no longer hide people's names, and the tools-panel toggle no longer shows through the menu.
- Retained the 0.1.6 restart-to-update fix, readable machine names, current machine labels in run details, and scrolling to your new message when sending from history.

Machine names can be edited under **Settings → Machines**. New names default to the macOS Computer Name; saved Beam aliases and explicit CLI names are preserved.

**Updating from 0.1.0–0.1.5:** if Restart to update stalls, wait until the update is downloaded, fully quit Beam with ⌘Q, then reopen it. Alternatively, quit Beam and replace the application with the downloaded installer. Version 0.1.6 already contains the restart fix.

Built from merged main commit `c66b796`, integrated with the previously published `v0.1.6` release and the People-menu fix. The release includes signed, notarized installers for Apple Silicon and Intel Macs.
