# Beam 0.1.9

- New PRs opened by Beam are ready for review instead of drafts.
- Agents can supply a descriptive PR title and body for their changes. Beam uses that title for the commit message and keeps the description for the Create PR action.
- Commits use the machine's configured Git identity, so GitHub can display your name and avatar. Beam remains the fallback when no Git identity is configured.
- Includes all desktop improvements and fixes from 0.1.8.

Signed and notarized installers are available for Apple Silicon and Intel Macs. Existing installations can update through Beam's updater.

**Updating from 0.1.0–0.1.5:** if Restart to update stalls, fully quit Beam after the download finishes, then reopen it. If necessary, quit Beam and replace it using the installer below.

Built from main commit `d63d46c`, retaining the published 0.1.8 release history.
