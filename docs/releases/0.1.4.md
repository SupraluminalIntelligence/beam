# Beam 0.1.4 — mention notifications

Release snapshot: `codex/release-0.1.4`, isolated from ongoing account-connection work. Retains the existing simulation/CAD features and runner selection behavior.

Human mentions produce persistent, message-linked inbox items. Native alerts request sound when enabled, use a delivery lease and acknowledgment, and retry failures. Inbox/banner clicks open and highlight the exact message. Access checks, mute settings and preferences apply. Beam must be running or hidden; fully-quit push is not included.

Validation: full workspace tests and type checks; notification UI checks with isolated fixtures; desktop, runner and production web builds; production backend schema validation and endpoint verification. A signed native notification smoke test was accepted by macOS. No test messages were sent to teammates.

The Convex backend is deployed to the existing production deployment. Published publicly on September 23, 2026: https://github.com/SupraluminalAI/beam-releases/releases/tag/v0.1.4.
