# Beam 0.1.5

Release snapshot: `codex/release-0.1.5`, based on the latest checkout at the start of release preparation. Includes account/profile and execution-machine selection, concurrent requester/agent runs with isolated work, shared workspace resources and authenticated previews, configurable usernames, and all 0.1.4 notification fixes.

Validation: full workspace tests and TypeScript checks; production desktop, runner and web builds; notification UI fixture checks with username selection; real Docker shared-command isolation test (4 tests passed); Convex schema validation and deployment to the existing production project. Existing independent-provider-login and non-macOS platform acceptance limits are recorded in `docs/agent-connections-plan.md`.

Every host accepting new runs needs the updated runner. Existing legacy runs may finish, but new runs require the work-isolation protocol acknowledgment. No running local app or active run was restarted during this release.
