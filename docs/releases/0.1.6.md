# Beam 0.1.6

- Fix Restart to update being cancelled by the close-to-background window handler. Show a restarting state, ignore repeated clicks, and retain the runner if installation fails.
- Use the macOS Computer Name for new machines and existing automatically generated username@hostname labels. Explicit CLI names and saved Beam aliases remain intact.
- Add clear Machine name controls in Settings → Accounts and machines with Save, Cancel, and inline errors. Names persist across restarts and appear in machine pickers and existing run details; historical execution records remain unchanged.
- After a successful send, smoothly scroll to the latest message and resume following replies. Incoming messages do not interrupt reading history; failed sends preserve the draft and scroll position. Respect reduced-motion preferences.

**Updating from 0.1.0–0.1.5:** if Restart to update does nothing, wait for the download to finish, fully quit Beam with ⌘Q, and reopen it. Those builds need this one-time workaround to install the restart fix.

Validation: updater shutdown-order regression tests; machine-name defaults, alias persistence and authorization tests; real browser fixture checks for Save/Cancel/error states and send-from-history scrolling, incoming messages, failed sends and reduced motion. No test messages are sent to live chats.
