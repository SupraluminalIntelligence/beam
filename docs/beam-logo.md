# Beam app icon

The selected mark is a monochrome focused beam, following Supraluminal’s cool black/off-white palette, film grain, and light-cone geometry. Approved September 20, 2026.

Source: `apps/desktop/build/beam-light-cone.png`. Native icon: `apps/desktop/build/beam.icns`. Resized copies appear in the sidebar and favicon. Earlier B concepts remain as design explorations only.

Generated with the built-in image generation tool using this prompt:

> Use case: logo-brand. Design a completely new macOS app icon for a physics-inspired collaboration app in Supraluminal's visual language. No lettering or monogram whatsoever. Brand language: severe scientific instrument, cool near-black #0b0c0e, cool off-white #e9ebef, restrained photographic film grain, stark light-cone geometry and generous negative space. Concept: a horizontal focused light beam, a luminous biconical envelope pinching to one tiny brilliant event point, then expanding again. The left cone is shorter and subdued, the right cone is longer and brighter: light propagating through a focus. A thin precise horizontal ray passes through both. Elegant flat triangular silhouette with softly etched optical density inside, like a monochrome long-exposure laboratory photograph distilled into a logo. Keep the symbol bold enough for a small dock icon, occupy middle 65 percent width, ample dark space above and below. Matte near-black rounded-square macOS tile, transparent outside tile. No teal, no purple, no rainbow, no chrome, no glossy bevels, no inflated 3D, no stars, no decorative orbit rings, no text, no B, no atom clipart. One icon only, square high-resolution production asset.
